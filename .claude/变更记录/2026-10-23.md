### 下午：阻断实验与噪声结构（纯调查，无代码改动）

**① 噪声模型**（16 个点，I 跨 950 倍，4 份归档）

```
σ² = a² + c²·I     a = 375 计数   c = 1.23   I* = 92,432
按距离分别拟合：3cm 的 a = 287，4cm 的 a = 540
```

底噪占噪声方差：670/4cm（I=2,143）**97.7%**，770/3cm（I=95,038）49.3%，
A2 的四路 4~35%。→ **I ≪ I\* 时加光是线性回报。**

- **依据**：实测
- **怎么确信的**：不是拿 4 个点拟合（第一次那样做错了），而是跨 4 份归档、
  光强从 2,143 到 2,036,680 共 16 个点；且先确认了必须拟合**扣暗后**的 σ，
  因为原始帧的 σ 与暗帧的 σ 几乎相等（3041 vs 3028），被共模主导
- **验证**：三种模型的中位相对残差 —— 纯散粒 57.4%、纯固定底 24.6%、混合 17.0%

**② TOI 误差预算**

```
λ      log比值噪声   ∂TOI/∂g    对TOI贡献   占方差
670      0.1086      -122.0      13.24     93.9%
770      0.0247      +137.1       3.39      6.1%
```

两波长灵敏度几乎相同，差别全在噪声。

**③ 尖峰的两种机制**

| | 体模 | 手臂 |
|---|---|---|
| 幅度/信号 | 2~5% | **100~193%** |
| 四路同时 | 0~7% | **100%** |
| 随信号缩放 | 否（加性） | **是（乘性）** |
| 加光有用吗 | 有 | **没有** |

手臂上是探头耦合瞬变（乘法因子），加光解决不了，只能剔除+告警。

- **怎么确信的**：① 跨 4 份归档比较「尖峰绝对幅度 vs 信号强度」，体模与手臂
  分成两个不相交的簇；② 独立检验尖峰不是固定值 —— 759 个样本里 757 个不同取值、
  0 个撞 ADC 轨道、帧头/长度/校验/保留区全部合法

**④ 阻断实验的一致性检验（非循环）**

SRS 只用 3cm/4cm 的**比值**反演，绝对光强没参与 → 可以拿绝对光强验反演。

```
λ   ρ    μa基线   μa阻断   预测 I 比   实测 I 比   实测/预测
670 3   0.1087  0.2118     0.089      0.431      4.8×
670 4   0.1087  0.2118     0.040      0.191      4.8×
770 3   0.1225  0.2412     0.086      0.455      5.3×
770 4   0.1225  0.2412     0.038      0.200      5.3×
```

**方向四通道全对**（μa 翻倍 ↔ 光强减半），**幅度系统性差 4.8~5.3 倍**。

- **依据**：实测
- **怎么确信的**：预测只用反演出的 μa 和假设的 μs′，实测只用绝对光强，
  两者数据来源独立。四通道偏差倍数一致（4.8/4.8/5.3/5.3）→ 系统性，不是噪声
- **推测（未验证）**：均匀半无限介质假设在活体上不成立。袖带主要影响深层肌肉，
  而 3/4cm 的"香蕉路径"浅层权重大 → 实际衰减远小于均匀模型的预测。
  另两个排不掉的候选：μs′ 也在变；袖带充气改变了探头耦合
- **影响**：**体模标出来的 k/b 搬到活体要打折扣**，这是 R5 的具体表现

  - `docs/验证图/界面_派生相对量.png`

**三个设计决定**（都写进了代码注释）：

1. **`derive()` 返回 `None` 而不是 NaN** —— 强迫调用方显式处理
   「还没设基线」，而不是把 NaN 画到曲线上
2. **按下校准时立刻把旧基线置 None** —— 攒新基线的那 30 秒里不该继续

3. **AUC 只累加低于基线的部分，且跳过 >10 s 的时间空洞** ——

**⚠️ 基线不抗漂移**：SRS 浓度 63% 的噪声在 <0.01 Hz，而 SRS **不能高通**
（会毁掉绝对值）。所以必须提供「重设基线」按钮 —— 竞品 BRS-100 同样如此

跨 9 份归档（N=20，取「耦合好的一半」以排除位移点）：

| 记录 | 670/4cm 扣暗后 | TOI std | 状态 |
|---|---|---|---|
| 164708 | 2,279 | **0.82** | 静止体模 |
| 141147 | 2,347 | **1.19** | 静止体模 |
| 103952 | 2,470 | **7.12** | 在体 |
| 105125 | 2,169 | **74.29** | 在体 |
| 112440 | 13,167 | 0.95 | 在体 |
| 134407 | 12,858 | 7.17 | 在体阻断 |
| 150038 | 23,974 | 1.53 | 在体 |
| 150943 | 20,611 | 2.08 | 手臂勒紧 |
| 111030 | 171,779 | **0.07** | A2 体模 |

幂律拟合 σ_TOI ∝ I^(−0.824)，但 **R²(log) 仅 0.417，n=9** —— 拟合不成立。
**同是 ~2,300 counts，静止体模 0.82/1.19，在体 7.12/74.29，差 60 倍；
而手臂在 20,611 counts（光强高 9 倍）下反而是 2.08。**
光强是必要条件，不是决定因素；决定因素是探头动没动。

⚠️ 这正是「作废：拟合指数 p = 0.71」那条踩过的同一个坑：
**把两个不相交的簇（静止 / 在体）硬塞进一条线**。这次在下结论前先看了 R²。

### ✗ 推翻（当晚提出、当晚更正）：「150943 的下降是采样偏倚造成的假趋势」

我先用 `prev` 扣暗 + 5 周期窗口分析，得到全部点 −3.10 %O2/min、
而「耦合好的一半」+0.20 %O2/min，于是判定下降是假的。
**换成 online 的生产配置（`interp` + N=20）后，这个结论不成立：**

| 配置 | n | TOI 均 | TOI std |
|---|---|---|---|
| prev + N=5（我第一版用的） | 137 | 69.04 | **217.55** |
| prev + N=20 | 123 | 88.28 | 1.49 |
| interp + N=5 | 135 | 88.22 | 2.69 |
| **interp + N=20（online 默认）** | 122 | 88.21 | **1.20** |
| interp + N=40 | 102 | 88.15 | 0.94 |

生产配置下 670/4cm 的摆幅只有 **1.58 倍**（15,128~23,928），
不是我说的 2.6 倍 —— 那 2.6 倍里大部分是 0.0868 Hz 窄带干扰，
N=20 的窗平均本来就把它压掉了。摆幅没了，「按光强分组」也就没有区分度，
分出来的两半斜率反而是 −2.24 / +0.60，与第一版正好相反。

**真实情况**：生产配置下趋势是 **−0.83 ± 0.43 %O2/min**，
205 s 合计约 −2.8 %O2，配合 tHb↑/HbR↑/HbO 平，是**真实的静脉淤血响应**，
不是伪迹，也不是动脉去饱和（那该是 −20~−30）。

**教训（可迁移，比结论重要）**：
**离线分析必须用生产配置复算，否则量化的是分析脚本而不是产品。**
我这次自己手写了扣暗和聚合，看着"等价"，实际换掉了两个环节。
正确做法是直接复用 `DarkSubtractor` + `aggregate` + `compute_toi`，
像 `docs/fig_occl_wobble.py` 更正后那样。

想法：稳健聚合保留样本的 `std/|均值|` 取各通道最大值，超阈就判该点不可信。
动机是现有 flags 抓不到耦合/运动。

### ⚠ 存疑：增大平均窗口不一定让 TOI 更稳

`134407_001`（探头中途脱开的那份）在 interp 模式下：
N=5 → std 29.98，N=20 → **20.32**，N=40 → **74.07**。
纯噪声平均不可能非单调。

**推测**（未验证）：窗口跨越光强阶跃时（该记录 670/4cm 从 3,697 跳到 53,098，
14 倍），MAD 剔不掉"半个窗口"，稳健均值给出一个两边之间的**合成值**，
看着是合法读数、没有任何 flag，N 越大跨越期越长。

这条只在有大幅阶跃的记录上出现；`150943`（无脱开）是单调的
29.98→20.32 对应的 2.69→1.20→0.94。**要验证需要构造带已知阶跃的仿真输入。**

### ✗ 推翻：「勒红 = 阻断成功」

红 / 紫胀是**静脉淤血**；动脉阻断的体征是**苍白、发凉**。
勒红说明压力卡在静脉压与动脉压之间 —— 回流断了、供血还在，
组织氧耗仍被满足，**TOI 生理上本就不该降**。
这与 `134407` 的判定（tHb 翻倍、轨迹沿等 TOI 射线）是同一结论，
两份数据互相印证。

### ✗ 推翻：「670 光强是主要矛盾」

我整个下午都以此为前提排优先级。**数据不支持它是唯一瓶颈：**

| 条件 | 670/4cm | N=20 TOI std |
|---|---|---|
| A2 体模静置 | 171,090 | 0.07 ✓ |
| **手臂静止** | **11,403** | **0.58 ✓** |
| 组织类体模静置 | 2,268 | 1.87 → N=40 时 1.22 ✓ |
| 手臂有动作 | — | 10.77 ✗ |

**±1 已经够得着**：手臂静止 N=20 达标，组织体模 N=40（61s）达标。
没达标的两行都是**动作伪影**，不是光强。

「670 占 TOI 噪声方差 93.9%」这个数**没错**，但我把它当成了唯一瓶颈。

**新的主要矛盾：TOI 对真实去饱和有没有响应，仍未验证**（见「悬而未决」）。

### ✗ 推翻：「噪声是纯固定底噪」

实为混合 `σ² = a² + c²I`，I\* = 92,432。只在 I ≪ I\* 的通道上近似为固定底。
第一次只用 4 个点、而且拟合的是**原始帧**（被共模主导）—— 那次结论站不住。

### ✗ 推翻：「670/770 波长选得不好，所以阻断时 TOI 不动」

实测分离度 **670/770 = 54.8 > 竞品 735/810 = 45.0**。我们的更好。
我在没算之前就下了这个判断。

### ✗ 作废：「尖峰 94% 正向」

那是把体模和手臂混在一起统计的。分开看：**体模 75~100% 正向，手臂 29~75%**，
手臂上有大量负向尖峰。**不同条件的数据不该合并统计。**

### ✗ 作废：拟合指数 p = 0.71（尖峰幅度 vs 信号强度）

把体模与手臂两个不相交的簇强行拟成一条线的产物，corr 只有 +0.376。
正确做法是分簇看。

### ✗ 推翻：「TOI 不动是因为基线 90% 太高、灵敏度被压缩」

我算错了方向。实测 **HbO +102% 比 HbR +78% 涨得更快**，所以任何基线下
TOI 都是上升的 —— 换基线改不了符号。

### ⚠ 降级：「慢漂是 LED 热漂」—— 证据不足，应标「推测」

支持：5 份里 4 份单调下降（1.4~3.9%）。
反对：① 幅度跨 8 倍（0.5% vs 3.9%）② 一份反向上升 8%
③ **暗电平无一致方向**（三份分别为 +0.3%、−17%、+17%），
而探测器暗电流随温升是明确增大的。

我前面多次说「LED 热漂」说得太肯定了。
