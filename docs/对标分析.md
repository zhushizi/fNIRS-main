### 1.2 MOC400 参数全集 ✅

| 参数 | 官网原文定义 |
|---|---|
| **rSO₂** | 局部脑组织氧饱和度，实时变化的数值 |
| **BL / ΔBL** | 「传感器置于监测部位病人在**平稳生理状态**下的 rSO₂ **初始值**」；ΔBL 为相对初始值的实时变化 |
| ΔO₂Hb / ΔHHb / ΔtHb | 氧合 / 脱氧 / 总血红蛋白浓度变化量 |
| AUC / TUT / AUT | 去饱容积；低于基线的累积时间；该时间占总监测时长的百分比 |

其他：三种传感器规格（成人/儿童/新生儿）；波动指数（±20% 绿 / ±30% 黄 / ±40% 红）；**适应症含急诊 ECPR、急性颅脑损伤、中毒**。

### 1.3 共同架构：SRS + MBLL 双通路 ⭕

```
多波长光强
   │
   ├─→ 空间分辨通路（多距离）
   │     解 μa(λ)（带未知缩放 k）
   │       ├─→ rSO₂ = C_HbO/(C_HbO+C_HbR)   k 约掉 → 绝对值
   │       └─→ THI  = k·(C_HbO+C_HbR)        k 保留 → 只能叫"指数"
   │
   └─→ MBLL 通路（微分）
         ΔOD → ΔO₂Hb、ΔHHb、ΔtHb（MOC 另加 ΔCyt）

BL/ΔBL、AUC/TUT/AUT、VOT 建立在 rSO₂ 之上
```

**"以修正朗伯-比尔定律为基本原理"描述的是 MBLL 通路**，也是最易向非专业读者解释的一条；rSO₂ 走的是另一条。

**参数集与 Hamamatsu NIRO-200NX 一一对应**（NIRO 的 TOI 由 SRS 算、Δ 量由 MBLL 算 ✅）：

| NIRO-200NX | MOC | BRS-100 |
|---|---|---|
| TOI | rSO₂ | 脑血氧饱和度 |
| THI / nTHI | THI / ΔTHI | THI |
| ΔHbO₂ / ΔHHb / ΔTHb | ΔO₂Hb / ΔHHb / ΔtHb | CHbO₂ / CHb / CtHb |

连命名习惯都一致（用 O₂Hb / HHb 而非更常见的 HbO / HbR）。

#### 支撑"rSO₂ 为连续绝对量"的证据

**BRS-100 说明书 3.4.2** ✅：

> 「开始监测后，**系统会自动计算基线**，监测过程中可点击基线校准按钮**重新校准基线**。**基线值在波形图中以虚线表示**。」

基线由系统自动计算、可随时重校、以虚线叠加显示——说明它只是一条参考线，rSO₂ 曲线独立存在。配合 BRS 的**绝对阈值报警**（高 85% / 低 55%）与 MOC 的**急诊适应症**（心脏骤停患者无"平稳生理状态"可取基线），三者互相印证。

### 1.4 三个技术要点

#### ① 绝对**浓度**与绝对**饱和度**是两回事

绝对衰减写全：

```
A(λ) = μa(λ)·L(λ) + G(λ)
       ↑          ↑        ↑
    想要的    未知光程   未知散射损失
```

微分测量 `ΔA(λ) = Δμa(λ)·L(λ)` 中 `G` 消失但 `L` 仍在，故只能得 `Δc·L`。

**但饱和度是比值**，`C_HbO` 与 `C_HbR` 的公共缩放误差在比值中约掉，因此对 `L` 的绝对值不敏感：

| 目标量 | CW 单距离能否得到 |
|---|---|
| Δc·L | ✅ 直接，无需标定 |
| **绝对饱和度 StO₂ (%)** | **⚠️ 可以**，需靠假设或经验标定约束 L(λ)、G(λ) |
| 绝对浓度 μM | ❌ 需多距离 / 频域 / 时域 |

> **类比脉搏血氧**：SpO₂ 设备同样宣称基于比尔-朗伯，但 `R → SpO₂` 对照表完全由人体去氧试验拟合（ISO 80601-2-61 要求人体试验）。**"以 MBLL 为原理"与"需要人体标定"不矛盾——前者是正向模型，后者是反演的最后一公里。**

#### ② 只有 2 个点时，"差值"与"斜率"是同一个运算

MOC200 称「评估**两个接收器光强的差异**」，同时又称算法为 SRS——两者不矛盾：

```
斜率 = (A₂ − A₁) / (ρ₂ − ρ₁)      Δρ 是常数 → 斜率 ∝ 差值
```

分野不在算术，而在如何解释这个差值：**代入扩散模型解 μa（SRS）**，还是**直接查标定曲线（经验减法，INVOS 式）**。

**因此 2 接收器 + 5 波长在数学上是完整的**，rSO₂ 与 THI 都能出。代价见 §3.4。

#### ③ 五波长的用途是补偿个体差异，不是解更多色团

**MOC200 原文** ✅：

> 「与五个波长光源组合，可以形成**多耦合光路**，降低不同患者**肤色、颅骨密度差异、皮下组织厚度**的差异性对数据精度影响。」

这构成一条清晰的设计哲学——**用波长多样性替代距离多样性**：

| 补偿手段 | 代表 |
|---|---|
| 增加波长（5 波长 × 2 接收器 = 10 条光路） | **MOC200 = 本项目** |
| 增加距离（2 波长 × 3 距离 = 6 条） | PortaLite |
| 两者都增加（5 × ≥3 = ≥15 条） | BRS |

> ⚠️ **关于 Cyt 的方法学提醒（对本项目同样适用）**：oxCCO 的主流测量手段是**宽带 NIRS 而非离散波长** ✅——其差分-氧化还原吸收峰宽而平缓，需连续光谱才能与血红蛋白可靠分离（代表系统 MAESTROS 为时域、2bNIRS 为 780–900 nm 宽带）。MOC 与本项目均用五个离散波长报 Cyt，方法学上偏激进；若对外声称 Cyt 定量准确性，需额外验证证据。**BRS 有五波长却不报 Cyt，可能正是出于这一顾虑。**

> ⭐ **本项目与 MOC200 的硬件配置完全一致**：1 组五波长 LED + 2 个接收器 + 同一贴片 + 10 条光路。**唯一未知的硬件差异是源探距离配置**，而这恰是最容易改的一项（改探头版图，不加器件、不影响采样率）。

**PortaLite 只有 2 个波长**，这决定了它的时分复用压力与"加光源位置"的选择——**均不适用于本项目**，故只作设计参照。

### 2.2 三个必须正视的实测差距

**① 主输出通道当前在输出噪声**（实测 `result_table/2026-07-16_15-52-29` ch2）

| 通道 | 光强 std/mean | ΔHbO rms |
|---|---|---|
| `S1_D1`（长距 30 mm） | **0.00043** | 1.8e-9 M |
| `S1_D1_ssr`（默认输出） | — | **2.8e-9 M ≈ 0.003 μM** |
| `S1_D2`（短距 10 mm） | 0.38 | 2.6e-5 M ≈ 26 μM |

长距撞顶 → SSR 的 β ≈ 0 → 校正量 ≈ 0 → 输出 ≈ 量化噪声。生理信号量级是几十 μM·cm。**此条不修，其余对比均无意义。**

**② 采样率差一个数量级**：1 Hz vs ≥10 Hz。GB/T 44423 要求全通道 ≥10 Hz。

**③ `thi` 不只是命名问题**：本项目 `thi = HbO_abs + HbR_abs`（由假设基线凑出的摩尔量）与行业 THI（由 μa 推出的无量纲指数）**不是同一物理量**。THI 必须从空间分辨通路得到。

### 2.3 核心结论：差距全是工程实现

**MOC200 用与本项目完全相同的硬件配置；BRS 只多一个接收器，且于 2021 年取得注册证、声称 ±2%、运行 ≥10 Hz。**

| 差距 | 性质 | 涉及架构变更 |
|---|---|---|
| 源探距离配置不当（10 mm 太浅） | 硬件，改探头版图 | ❌ |
| 长距饱和、无分探测器增益 | 硬件/固件 | ❌ |
| 采样率 1 Hz | 固件时序 | ❌ |
| 无空间分辨反演 | 软件 | ❌ |
| 无绝对衰减标定 | 工艺 | ❌ |
| 无准确度标定 | 标定/临床 | ❌ |
| （追平 BRS）少 1 个接收器 | 硬件，可选 | ❌ |

**没有一条是"路线选错了"。全部为把已有骨架补完整的工程工作。**

## 3. 改造方案

### 3.1 ⭐ 三档方案对比

| | **方案一：只挪位置** | **方案二：加 1 路** | **方案三：加 2 路** |
|---|---|---|---|
| 硬件改动 | **仅改探头版图**，不加器件 | +1 路 PD/TIA/ADC | +2 路 |
| 接收器 | 2 | 3 | 4 |
| 距离 | 约 20 / 30 mm | 10 / 30 / 40 mm | 10 / 30 / 35 / 40 mm |
| 对标 | **MOC200**（硬件一致） | INVOS 式 | BRS / NIRO / PortaLite 式 |
| 空间分辨点数 | 2 | 2（另留超短距做 SSR） | **3** |
| 能出 rSO₂ / THI | ✅ / ✅ | ✅ / ✅ | ✅ / ✅ |
| **拟合残差可诊断** | ❌ | ❌ | ✅ |
| 保留超短距 SSR | ❌ 牺牲 | ✅ | ✅ |
| 采样率影响 | 无 | 无 | 无 |
| 成本 | **最低** | 低 | 中 |

**选择依据**：若确认 MOC200 两个距离都在 20~40 mm 区间 → **方案一**成本最低且有商业产品验证；若要保留超短距 SSR（本项目现有差异化功能）→ 方案二起步；若要在开发阶段能自查 → 方案三。

> ⚠️ **方案一的前提是拿到 MOC200 的实际距离**（见 §5）。在此之前不要盲目挪——挪错了既丢 SSR，又换不来有效的空间分辨。

### 3.2 ⭐ 若要增加点数：加探测器，不加光源位置

由光学互易性，多距离可用**多光源位置 + 单探测器**（PortaLite）或**单光源 + 多探测器**（NIRO、INVOS、BRS）实现。两者数学等价，但**对五波长系统代价差别极大**。

**关键事实：探测器并行采样。** 本项目原始数据中两个探测器共用同一时间戳：

```
Time      DetectorId  Wavelength  Value
0.698974      1           2       6620836   ← S1_D1
0.698974      2           2        914534   ← S1_D2
```

| | 加光源位置 | **加探测器** |
|---|---|---|
| 时分轮转组数 | 5 → 15（×3） | **不变** |
| **有效采样率** | 1 Hz → **0.33 Hz** | **不受影响** |
| 需要增加 | 一整组 5 波长 LED + 驱动 | 1 路 PD + TIA + ADC |
| 配对键数 | 10 → 30 | 10 → **20** |

**PortaLite 加光源位置，是因为它只有 2 个波长**（3 位置 × 2 波长 = 6 组，仍跑 100 Hz）。本项目五波长，加位置的时分代价是它的 2.5 倍。**BRS 同为五波长系统，选择的正是"1 组光源 + ≥3 接收器"。**

### 3.3 几何设计要点

**① 短距通道与 SRS 距离是两组独立的东西**

PortaLite 的两组距离完全分开 ✅：

| 用途 | 距离 | 作用 |
|---|---|---|
| **短距通道** | **7.2 / 8.0 mm** | 只看浅层，用于头皮干扰抑制 |
| **SRS 距离** | **29 / 35 / 41 mm** | 紧密排布的远距离，拟合斜率出 TSI |

**短距不参与 SRS 斜率计算**，且它把短距做得比本项目的 10 mm 还短，正是为让其纯粹只采样浅层。

> **本项目的 10 mm 短距不能当 SRS 的第二个点**——10 mm 基本只走头皮，30 mm 含深层，两点跨越不同组织层，违反 SRS 的均匀半无限介质假设。**不是"点数不够"，是"点选错了"。**

**② 每个波长必须在所有距离上都有测量值**

PortaLite 规格原文是「3 LEDs, **each with 2 wavelengths**」——3 个位置各发全部 2 个波长。因为：

```
对波长 λ：  A(λ, ρ₁)  A(λ, ρ₂)  A(λ, ρ₃)  →  拟合 ∂A/∂ρ  →  μa(λ)
```

若各位置发不同波长，每个波长只剩一个距离点，斜率无从谈起。**波长维度与距离维度正交。**

**③ 建议几何**

```
[光源]──7~10mm──[PD短]────────30mm────────[PD1]──5mm──[PD2]──5mm──[PD3]
  5波长                                    └──────── SRS 三点 ────────┘
                                                 30 / 35 / 40 mm
```

**参考锚点**：INVOS 用 30/40 mm，PortaLite 用 29/35/41 mm，成人脑氧商用设备普遍在 30~40 mm 区间。

### 3.4 ⚠️ 加探测器带来的三个新约束

**① 探测器间增益一致性成为关键**

这是加探测器相对加光源的唯一劣势，两者对称：

- 加光源：各位置共用同一 PD → PD 增益约掉，但**LED 位置间输出功率差**偏移斜率
- 加探测器：共用同一光源 → 光源功率约掉，但**探测器间响应度/TIA 增益差**偏移斜率

**必须在体模上做探测器间增益标定**（见 §4.1④）。好处是 PD + TIA 的长期漂移通常小于 LED 输出漂移。

**② 各探测器需独立增益档位**

衰减随距离近似指数上升，30→40 mm 可能掉一个数量级以上：`10mm 最亮 ── 30mm 中 ── 40mm 最暗`。

**三个探测器不能共用一档增益。** 本项目当前长距撞顶，本质上就是没有分别配增益——**修饱和时应顺手把"每探测器独立增益"的架构做进去**。

**③ 光学串扰**

探测器数量增加、间距变近，探头基板内漏光风险上升，需做光学隔离。GB 9706.271 **201.12.1.101.9 信号串扰**（XT = 20·log₁₀|V₀/V|）正是测这个，且该条要求**按正常使用排列**测试——一体式探头可直接执行，无需工装。

**④ 2 点与 3 点的取舍**

2 点数学上够拟合斜率（即 INVOS 几何），但：

| | 2 点 | 3 点 |
|---|---|---|
| 能算斜率 | ✅ | ✅ |
| **能检验扩散模型是否成立** | ❌ 残差恒为零 | ✅ 看拟合残差 |
| 单个探测器耦合异常 | **无法察觉，直接扭曲斜率** | 残差会暴露 |

## 4. 标定

### 4.1 硬件级标定（出厂／工厂）

目的：把原始电压转换成与组织光学参数相关的量，消除器件个体差异，保证台间与探头间一致性。

| 步骤 | 内容 | 方法与依据 |
|---|---|---|
| **① 光源参数** | 每个发射探头、每个波长的**峰值波长、FWHM、平均光功率** | **功率计**测光功率、**分光光度计/光谱分析仪**测波长与 FWHM，**直接对着发射探头测**，不经过体模。脉冲输出用 `P_av = P_peak × τ × f`。须在 GB 7247.1 皮肤 MPE 限值内<br>*GB 9706.271 201.12.1.101.2/.3/.4，图 201.102、201.103* |
| **② 探测器暗电流** | 完全遮光下记录各探测器暗电压 | — |
| **③ 探测器响应度** | 已知光强照射，测响应度（V/μW） | — |
| **④ 探测器间增益一致性** | 均匀体模上标定各探测器增益系数 | ⭐ **2 接收器架构的命门**（见 §3.4①） |
| **⑤ 绝对衰减基准** | 已知光学性质的体模上定出绝对基准，折算未知的入射光强与散射损失 | 微分测量不需要，绝对测量必需 |
| **⑥ μa 覆盖标定** | **3~5 组不同 μa** 的标准体模，建立反演关系并检验线性度 | *GB/T 44423 7.4.6：R² ≥ 0.95，浓度跨度 ≥15 dB* |
| **⑦ 出厂一致性校验** | 同一标准体模测所有出厂探头，超差返工 | *GB/T 44423 7.4.7：U = (1−σ/μ)×100% ≥ 90%* |

#### SRS 反演的数学形式

半无限均匀介质的漫反射在扩散近似下满足 `R(ρ) ∝ (1/ρ²)·exp(−μeff·ρ)`，取 `A = −log₁₀R` 后 `∂A/∂ρ = (1/ln10)·[μeff + 2/ρ]`。由此反解：

```
① 测斜率      S = [A(ρ_far) − A(ρ_near)] / (ρ_far − ρ_near)     单位 OD/cm
② 扣几何项    μeff = ln(10)·S − 2/ρ̄                            ρ̄ 取有效距离
③ 解吸收系数  μa = μeff² / (3·μs′)                              ← 平方关系
④ 散射假设    μs′(λ) = a·λ^(−b)                                 ← Mie 幂律，须假设
⑤ 色团分解    由多波长 μa(λ) 解 C_HbO、C_HbR
⑥ 输出        rSO₂ = C_HbO/(C_HbO+C_HbR)    THI = k·(C_HbO+C_HbR)
```

三点须注意：**μa 与斜率是平方关系**；**`2/ρ` 几何项必须扣除**（仅 2 点时 ρ̄ 取有效距离）；具体系数随所采用的扩散模型与边界条件而异，实施前须固定一套模型并在体模上验证。

> **术语**：约化的是**散射**系数 μs′（reduced scattering coefficient）；吸收系数即 μa。

#### 两条通路的标定对象不同

| 通路 | 需要什么 | 本项目现状 |
|---|---|---|
| **MBLL（微分）** | **DPF(λ, 年龄)**，把 Δc·L 换算为 Δc | ✅ 已有：`mbll_core.py` 的 `get_dpf()`（Scholkmann & Wolf 公式） |
| **SRS（空间分辨）** | **μs′ 幂律参数 a、b**；**不经过光程，不需要 DPF** | ❌ 无 |

### 4.2 人体标定（型式标定，一次性）

硬件标定给出的是组织光学参数；**从光学量到临床 rSO₂ 之间的系统偏差**（动静脉加权与金标准定义的差异、颅外污染、部分容积效应、μs′ 假设误差）只能由人体在体实验校正。

#### 流程（GB 9706.285—20XX 立项稿 201.12.1.101.2）

| 步骤 | 内容 |
|---|---|
| **① 受试者** | 健康志愿者；须披露人群的解剖学、生理学与病理生理学范围，以及**肤色、年龄、性别**构成（201.12.1.101.4） |
| **② 置管** | 桡动脉（取 SaO₂）+ 颈内静脉逆行置管至**颈静脉球部**（取 SjvO₂） |
| **③ 受控降氧** | 混合气逐级降低 FiO₂，设多个稳定平台，覆盖**整个声称范围（下限上偏 3%、上限下偏 3%）**，各平台数据点密度相当 |
| **④ 同步采样** | 每个平台同时记录设备读数与动脉、颈静脉血样 |
| **⑤ 参考值** | **一氧化碳-血气分析仪（Co-oximeter）**分析。分析仪性能须优于所抽血样范围 1%（1 SD）或更好 |

#### 参考真值与准确度指标

```
SavO₂ = R · SaO₂ + (1 − R) · SjvO₂
```

- `R` = 动脉血分数，取自**探头下方脑组织的动静脉血量假设比**；行业常用 R = 0.25~0.30
- ⚠️ **强制要求在使用说明书中披露所采用的 R**（201.12.1.101.3 c) 2）

| 指标 | 要求 |
|---|---|
| **StO₂ 准确度** | 设备测量值与参考值之差的**均方根（Arms）**；50%~85% 范围内 **Arms ≤ 10% StO₂** |
| 趋势准确度 | 可选。⚠️ 标准原文：「在撰写本文件时，**未就趋势准确度的报告方法达成共识**」 |
| 须提供的图表 | rSO₂ 对 SR 的**散点图**（含网格线与 y=x 一致度线）及回归参数、**Bland-Altman 图**、总体平均偏差 μ₀、受试者间/内方差、95% 一致性限值 |
| 说明书须注明 | 因测量值呈统计概率分布，**约 2/3 落在 Co-oximeter 值的 ±Arms 之内** |

> **人体标定是一次性型式标定，不是逐台标定。** 最终参数（R、消光系数、散射假设）写入固件，量产设备只做硬件级出厂一致性校验（§4.1⑦）。
>
> ⚠️ **小儿患者的准确度不能由成人受控降氧研究支持**，须另行针对预期人群做便利样本研究（201.12.1.101.2 d）。

### 4.3 ⭐ 法规门槛可能低于预期

BRS-100 说明书对**脉搏血氧**的准确度来源有完整披露（ISO 80601-2-61 强制内容）✅：

> 「**功能测试仪不能用于评价脉搏血氧探头和脉搏血氧监护仪的准确度。**」
> 「建立指脉血氧饱和度准确度声称的测试方法总结：利用**反射式指脉氧模拟仪**……」

**而脑血氧与组织血氧的 ±2% 是如何建立的，说明书只字未提。**

| 观察 | ⭕ 推断 |
|---|---|
| 仅 SpO₂ 披露标定来源 | SpO₂ 有强制专用标准要求披露；脑血氧在 2021 年注册时无专用标准，无披露义务 |
