本文只涵盖透射式体模试验（101.5 / .6 / .7 / .8）及其前置条件。反射式工程验证、合成输入的软件层验证、人体生理试验均不在本文范围。

1被检性能与测量量

1.1　测量量是 Δc·L

本设备基于修正比尔-朗伯定律（MBLL）测量路径长度依赖的血红蛋白变化量 Δc·L，不测量绝对血氧饱和度。

附录 BB.2 原文：「Δμa 和 L 的值不能单独从连续光的测量中得到，而是得到它们的乘积 μa(λ)·L。」

「平均光程长 L 目前很难被测量。因此，测量的物理量 ΔcO₂HbL 和 ΔcHHbL 是血红蛋白浓度变化和平均光程长的乘积，它们的单位用浓度和距离的乘积表示，如 (mmol/L)·mm。」

平均光程 L 为假设值（DPF 公式与年龄参数须在说明书披露），不在本方法的验证范围内。

1.2　为什么用透射法

BB.3.1 原文：「采用透射法是因为它容易改变光的衰减，测量精度好；而反射法通常用于较厚的人体组织。」

附录 BB 为规范性附录，201.12.1.101.5 全文即指向它，其试验构型为透射。

体模验不出生理反相，这是标准自己写明的。孔径是几何机制，五波长 ΔA 相等，解出必同号：

BB.3.1 算例注 1：「在 690 nm 和 830 nm 衰减增加 3 dB 时，模拟的路径长度依赖的血红蛋白变化量均为阳性。」

标准接受这一点——本试验检的是数值准确度，不是生理仿真。生理反相需人体试验，不在本文范围。

4【101.5】路径长度依赖的血红蛋白变化量

101.5 全文：「应对路径长度依赖的血红蛋白变化量进行测量并在使用说明书中给出。通过检查使用说明书和附录 BB 中描述的试验来检验是否符合要求。」

4.1　原理

BB.3.1 原文：「通过改变光学孔径面积来改变透射光强，相当于改变了整个功能性近红外光谱体模的吸收系数 μa。孔径面积的比值 (SapB/SapA) 表示透射光强的比值 (IB/IA)。光的方向性丢失是由于在光学孔径的前后放置了足够厚的散射和吸收材料，导致 SapB/SapA 等于 IB/IA。」

SapBSapA = IBIA
BB.3.1

孔径面积比精确等于透射光强比——几何即溯源，不需要体模的任何光学属性（μa、μs′、厚度、折射率均不需要）。

孔径改变的是几何遮挡，并未改变体模材料的 μa。但设备只能看到探测光强 I，无法区分「介质吸收变强」与「一部分光被挡住」，二者产生的 ΔA 完全相同。故标准称其「相当于改变了吸收系数」——这是等效，不是物理改变。

与真实组织的差别：真实 μa 变化时有效光程 L 也会微变；孔径变化时 L 完全恒定。因此本试验是对反演链路更「干净」的检验。

4.4　五波长求解

ΔA = E · x　　　　x = pinv(E) · ΔA
BB.4/.5 推广

E 为 5×2 消光系数矩阵（不含光程——L 已包含在未知数 x = Δc·L 中）。超定，取最小二乘解。

实测 cond(E) = 3.58（奇异值 3232.9 / 902.6），条件数小，五波长冗余良好。单波长 +1% 增益误差 → Δc 误差约 1.06%，不放大。

五个波长在最小二乘中等权，某个波长信噪比差会直接污染解——故须做判据 A2 的波长一致性检查。

前置 1. 完成 §2 全部前置条件（R1、R2、R4，101.3 峰值波长） 2. 按 §2.4 选定并记录探头组合 3. 按 §3 搭建体模与遮光 参考侧 4. 体模、光源、探测器固定在遮光箱内，位置一经确定全程不动 （BB.2）5. 光源预热至稳定，记录 15 min 输出波动 6. 孔径置状态 A，逐波长测 I_A，重复 N≥10 次取均值 7. 孔径切状态 B，测 I_B，同样 N≥10 次（切孔径时不要碰体模和探测器） 8. 切回 A 再测一次（回差检查），与第 6 步差 >1% 则本轮作废 9. 整个 A→B→A 循环重复 ≥3 次 10. 按 BB.2 算 ΔA_ref，按 §4.4 算 x_ref 设备侧 11. 同一块体模、同一位置，只把光源与功率计换成设备的两个探头 （BB.3）12. 孔径 A→B→A，各采集 ≥60 s，切换时刻打事件标记 13. 重复 ≥5 次 14. 去掉切换后过渡段（前 10 s），取稳定段均值得 I_A、I_B 15. 按完全相同的公式与 E 矩阵算 x_dev 比较 16. 计算相对偏差，判 A1~A4

不要用在线管线跑此试验。intensities_to_od_changes 在 refs=None 时用本段时间均值做参考，因果模式下用热身窗冻结基线，两者都不是「状态 A 相对状态 B」；带通滤波还会削掉阶跃。应记录原始光强后离线计算。

5【101.6】信号稳定性

装置：发射探头 →〔衰减器 6〕→ 接收探头（图 201.104）。

101.6 b) 原文：「衰减器由滤光片或散射、吸收的衰减材料制成，对每一适用波长有大于 40 dB 的光损耗。光损耗是预先用光功率计测量的，或者，如果是滤光片，则用分光光度计测量。」

步骤：c) 充分预热 → d) 功率设为最大 → e) 连续采集 > 15 min，用时间常数 < 5 s 的低通滤波器处理 → f) 针对氧合与脱氧血红蛋白分别计算。

Sstab = √Σj=1..k { (Δc·L)j − Δc·L }²k − 1
公式 2

k 为时间序列中样本的个数。即 Δc·L 时间序列的样本标准差——衰减器全程不变，测的是设备自身的漂移与噪声。

原文注：「Δc·L 与基线样本的变化有关，而与衰减的变化无关。」

取氧合与脱氧血红蛋白两者中 Sstab 的较大值作为信号稳定性。

序号判据
B1测量 Sstab 并在使用说明书中给出（标准不设限值）

6【101.7】响应时间

装置：发射探头 →〔衰减器｜光学快门｜衰减器〕→ 接收探头（图 201.105）。快门关闭时光损耗无穷大，开启时 > 40 dB。

快门切换时间应小于 ME 设备的响应时间（GB 版新增，201.12.1.107）。

方法：测快门切换引起的 Δc·L 阶跃响应，取幅度在 10% 与 90% 之间的时间间隔（图 201.106）。

序号判据
C1测量响应时间（上升时间／下降时间）并在使用说明书中给出

当前配对采样率约 1 Hz，时间分辨率 1000 ms；且 BP_HIGH_HZ = 0.1 的带通会进一步拖慢阶跃。按实测值如实报告。

7【101.8】信噪比

装置：ME 设备 + 一个光学孔径 + 两个衰减器（图 201.107）。

状态光损耗
A> 60 dB
B比 A 大 3~4 dB

步骤：c) ME 设备处于最高采样率；信号变化应进行 ≥ 4 次重复测量，每次包括 ≥ 10 个采样点。

SA = Δc·LA = Σj=1..m (Δc·L)j,Am　　　S = SA − SB
公式 4
δS = √Σi=1..n ( Σj=1..m { (Δc·L)j,A − Δc·LA }² )m · n − 1　　信噪比 = S / δS
公式 3

m 为采样事件数（≥ 10），n 为重复次数（≥ 4）。

必须使用 GB 版公式。GB 9706.271 前言载明：「更改了信噪比中标准差 δS 的计算公式（见 201.12.1.101.8），国际标准公式编辑错误，对其进行更正」。

注意本项为「自比」结构：(Δc·L) 全部来自 ME 设备自身输出，功率计不参与，检的是响应的稳定性与可重复性。

101.8 e)：通过测量得到路径长度依赖的血红蛋白变化量、路径长度依赖的氧合血红蛋白变化量和路径长度依赖的脱氧血红蛋白变化量。

序号判据
D1测量信噪比并在使用说明书中给出
D2同时声称最大采样率（标准强制）

8离线核验工具

只能离线

附录 BB 的流程本身就是两阶段（参考系统先测 → 设备后测 → 比较），参考侧还是功率计人工读数，不存在在线通路。101.6/.7/.8 同理：采集在线（101.8 还要求最高采样率），计算全部离线。

8.1　不需要重写算法

项目里两个函数本身就是标准公式，只要传对参数：

ΔA = intensities_to_od_changes(I_B.reshape(-1,1), refs=I_A) # = BB.2 x = generalized_mbll(ΔA, WL, dpfs=[1.0]*5, distance_cm=1.0) # = BB.3~BB.5

实测与独立 numpy 实现差 0.000e+00（ΔA 和 Δc·L 都是）。

关键参数 dpfs=1, distance_cm=1

a_hb = hb_ex * pathlength[:,None]，pathlength = DPF × d。令其为 1 时 a_hb 退化为纯 ε 矩阵，输出即标准的被测量 Δc·L，而非除过光程的 Δc。

不能用实际 DPF 再乘回去换算——DPF 随波长变（15.44~18.68 cm），改变了最小二乘的加权，没有任何单一 L 能同时对上两条：用 850nm 的 15.44 cm 换算，HbO 偏 +4.22%、HbR 偏 −28.62%。

8.2　组件取舍

组件能否用原因
intensities_to_od_changes(refs=I_A)✓传显式 refs 就是 BB.2
intensities_to_od_changes(refs=None)✗会用本段时间均值做基线，不是「A 相对 B」
generalized_mbll✓传 dpf=1, d=1
hemoglobin_extinctions✓ε 表

8.3　交叉核对（必做）

参考侧和设备侧若都调同一个 generalized_mbll，反演代码里的 bug 会两边抵消，5% 判据对它是盲的。

堵法：参考侧的 Δc·L 算两遍——一遍用项目函数，一遍用独立实现。一致就说明反演无误，之后放心两边都用项目函数。

这样 5% 判据检光强测量链，交叉核对检反演实现，两个洞都堵上。

8.4　脚本

tools/verify_bb.py 已实现上述全部内容。

python tools/verify_bb.py --selftest python tools/verify_bb.py --ref ref.csv \ --raw result_table/xxx/all_groups.csv \ --acq-channel 2 --detector S1_D1 \ --seg-a 30:90 --seg-b 130:190 \ --aperture-ratio 0.447

参考侧 CSV 三列：wavelength_nm,I_A,I_B，五行。输出 BB.2 的 ΔA、五波长一致性、孔径几何校验、反演交叉核对、Δc·L 参考值/设备值、A1~A4 判据。退出码 0/1。

自检含元测试：850 nm 人为加 8% 增益偏差 → A1 判 FAIL（HbO 10.05%、HbR 5.64%）；无偏差时全 PASS。证明判据会咬。

由此反推：单波长增益一致性需优于约 4% 才能稳过 A1。建议整定增益时按此卡。

3 · 测量量的定义与假设声明（必写）

本方法验证路径长度依赖的血红蛋白变化量 Δc·L 的幅度准确度。平均光程 L 为假设值（DPF 公式与年龄参数已在说明书披露），不在本试验验证范围内。

4 · 验证边界声明（必写）

本试验采用 GB 9706.271—2022 附录 BB 的变孔径体模。该体模产生的光强变化在各波长上相同，据 BB.3.1 注 1，解出的 ΔcO₂Hb·L 与 ΔcHHb·L 同号；据注 3，其大小与方向与人体脑激活不同。本试验验证的是设备对已知光强变化的数值准确度（< 5%），不涵盖生理条件下的方向性。

5 · BB.5 更正说明（必写）

计算中 ΔcHHb·L 采用克拉默法则形式（等价于 pinv 最小二乘解）。GB 9706.271—2022 公式 BB.5 印刷的分子两项次序与其自身算例（BB.3.1，结果 +111 μmol/L·cm，注 1 载明「均为阳性」）不符，直接实现会导致符号相反。
