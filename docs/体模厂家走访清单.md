# 体模厂家走访清单

**对象**：上海模辉科技（BestView）
**目的**：核实其测量能力、配方特性、分层与液体体模的实际能力，判断"完整方案"是否适用于 SRS 路线

---

## 0. 先建立一个判断基准

⚠️ **他们的论文（JBP 2026）用的是 DOT 成像思路**——在均匀背景里埋 Φ6mm 腔体，然后成像找出来。

**SRS 不成像，测的是体块平均光学参数。** 两者对体模的要求不同：

| | DOT / 成像 | **SRS** |
|---|---|---|
| 要什么 | 背景 + 小异物（对比度） | **体块均匀 + 已知绝对值** |
| 腔体尺寸 | 小（异物） | **大**（要主导测量体积） |
| 关键指标 | 对比度、位置精度 | **块间一致性、长期稳定性** |

⭐ **开场先问一句**：「你们之前给脑血氧（rSO₂）设备做过标定体模吗？流程是什么样的？」

**答案决定后面怎么谈**——如果他们主要服务成像客户，那"完整方案"需要重新对齐。

---

## 1. 五个决定成败的问题（优先级最高）

### ⭐ Q1：TiO₂ 在 700~850 nm 对 μa 的贡献占多少？

**为什么问**：这是**自标定能否成立**的根源。

各块散射档位不同 → TiO₂ 投料量不同 → 对 μa 的贡献跟着变 → **吸收谱形在块间漂移**。

| TiO₂ 吸收贡献 | 后果 |
|---|---|
| **< 1%** | ✅ 风险消失 |
| ~10% | ❌ 谱形漂移 2% 就使自标定误差超标 **7 倍**，且**残差看不出来** |

**追问**：有没有测过纯 TiO₂ 基体（不加吸收剂）的 μa？

### ⭐ Q2：块间相对精度（重复性）是多少？不是绝对不确定度

**为什么问**：交叉验证的灵敏度完全取决于这个数。

| 块间相对精度 | 能检出 2% 谱形漂移的概率 |
|---|---|
| 5%（IAD 绝对不确定度典型值） | **7.3%** ❌ |
| **1%** | **95.8%** ✅ |

IAD 的 4~5% 绝对不确定度里大部分是系统项（积分球标定、样品厚度、参考白板），**同批测量时是共模、会约掉**。

**要的是同批测量条件下的块间相对精度，目标 ≤1%。**

### ⭐ Q3：能不能做 μs′ ≈ 0.3 cm⁻¹ 的低散射层？

**为什么问**：模拟脑脊液（CSF）。比常规体模低 **30 倍**。

做不到 → 三层退化成两层 → **光管效应验不了**，而那是目前最大的技术未知。

### ⭐ Q4：分层体模叠放时，层间怎么处理？

需要匹配液（甘油/水）还是干贴？空气间隙多厚？

**空气间隙会引入额外界面反射，破坏分层等效性。**

**现场要看**：有没有现成的分层样品，实际叠一下看贴合度。

### ⭐ Q5：血液体模的构型——是留腔还是液体系统？

他们答复过「一般我们留好腔体，你们自己去灌血液」。

⚠️ **Φ6mm 的腔对 SRS 无效**：ρ=3~5cm 的敏感区体积约十余 cm³，Φ6mm 腔只有 0.85 cm³（占比约 5%），**腔内血液降氧几乎不改变体块 μa**。

**要的是液体体模系统**：Intralipid + 全血 + 容器 + 脱氧装置，探头贴壁测。

**问**：做过这种吗？容器构型？还是只做固体腔？

## 5. 现场最好能做的两件事

**① 借他们的设备测一块**

如果能带探头去，在他们的样品上实测一次，对比他们的认证值。**这是最快的能力核实。**

**② 看他们给别的脑氧客户做过什么**

不必看具体客户，看**流程文档**：他们的标定服务包含哪些步骤、交付什么。

⚠️ 如果答案是"我们只提供体模，标定你们自己做"——那"完整方案"就是话术，要据此调整期望。

## 6. 判断"完整方案"含金量的三个信号

| 信号 | 含义 |
|---|---|
| 能说清 **SRS 和 DOT 对体模要求的区别** | ✅ 真懂 |
| 主动提到**块间一致性**、**长期稳定性**而非只谈绝对精度 | ✅ 真懂 |
| 做过**液体降氧**或**分层**体模的实例 | ✅ 有经验 |
| 只强调"我们数据库上万组""精度高" | ⚠️ 销售话术 |
| 把 SRS 当成 DOT 谈 | ⚠️ 需要重新对齐 |

## 附：不要在现场承诺的事

⚠️ **不要当场敲定 3×4 矩阵的订单。**

按前面的分析，优先级排序是：

1. 注册路径咨询（非技术，卡住全废）
2. 修长距饱和
3. FTO 检索
4. **分层体模**（补最大缺口，还能验 SSR）
5. 液体降氧体模
6. 单块 + 功率计验硬件
7. **3×4 矩阵**（风险最低，可最后做）

**矩阵不是分水岭，分层才是。** 现场可以谈，但先把分层体模的能力问清楚再定采购顺序。
